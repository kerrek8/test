# Тестовое Neowise. AI-помощник для входящих заявок

Менеджер вводит текст заявки, получает тему и черновик ответа. Он читает результат и сам решает, что отправить клиенту.

## Требования

- Node.js 20 или новее.
- Зависимостей и ключей нет (zero-dependency).

## Запуск приложения

```sh
node server.mjs
```

После запуска откройте http://127.0.0.1:3000 в браузере. Порт можно переопределить через переменную окружения `PORT` (по умолчанию `3000`).

## Запуск тестов

Для запуска встроенного набора тестов поведения при сбоях и валидации ввода выполните:

```sh
node --test test.mjs
```

Тесты проверяют:
1. Поведение при ошибке имитатора AI (`[error]`) → fallback на `manual_review`.
2. Таймаут вызова модели (`[timeout]`) → ограничение до 300 мс и возврат `manual_review`.
3. Некорректный JSON от модели (`[bad-json]`) → fallback на `manual_review`.
4. Недопустимую тему (`[bad-topic]`) → fallback на `manual_review`.
5. Пустой черновик от модели (`[empty-draft]`) → fallback на `manual_review`.
6. Валидацию ввода: пустой ввод / пробелы → HTTP 400 `{"status":"invalid_input"}`.
